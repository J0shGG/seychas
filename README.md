# Сейчас

Фокус-приложение с одним правилом: в каждый момент горит свет только над одной задачей.

## Десктоп

Собрать установщик и портативный `.exe`:

```bash
cd C:\Users\vladi\source\repos\seychas
npm install
npm run dist
```

Готовые файлы появятся в `release\`:

- `Seychas.exe` — можно сразу запускать, никуда ставить не нужно
- `Seychas-Setup.exe` — ставит ярлык «Сейчас» на рабочий стол и в меню Пуск

Запуск в режиме разработки (окно приложения + горячая перезагрузка):

```bash
npm run desktop
```

## Браузер

```bash
npm run dev
```

Открой http://127.0.0.1:5173

## Как пользоваться

1. Напиши, что сегодня важно.
2. Положи задачи на стол.
3. Выбери одну и нажми **Зажечь лампу**.
4. Если пришла посторонняя мысль — запиши её внизу и вернись к делу.
5. Когда круг закончится, отдохни или зажги лампу снова.

Данные живут на этом компьютере (localStorage). Сервер не нужен.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| `N` | Новая задача |
| `Пробел` | Зажечь / пауза / продолжить |
| `Enter` | Отметить текущую готовой |
| `Esc` | Отпустить сессию |
| `F` | Полный экран |

В настройках (✶) можно выбрать 15 / 25 / 50 / 90 минут, тихий фон (дождь, огонь, кафе) и колокол в конце круга.

Каждый зачтённый круг пишется в дневник: календарь в правой колонке и кнопка «Все дни» (или иконка календаря в шапке). Там видно, сколько ты работал в каждый день, за неделю и за месяц.
